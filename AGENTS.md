# ArrowPuzzle — agent instructions

Unity puzzle game: drag arrowheads along Catmull-Rom paths, avoid collisions, complete all lines to win.

## Unity version (critical)
- **Unity 6000.3.9f1** (`ProjectSettings/ProjectVersion.txt`). Open the project with exactly this version.
- The project folder *is* the Unity project: open `C:\Unity\Internship3\ArrowPuzzle` in Unity Hub, not a subfolder.

## Entry point / how to run
- Single scene: `Assets/Scenes/GameScene.unity` (the only scene; make sure it's in Build Settings before building — `GameUIController.Retry` reloads the active scene by build index).
- Press Play in the Editor. No CLI build/test commands exist; `.csproj`/`.sln` are gitignored and regenerated by Unity.
- No test framework usage, no CI workflows, no pre-commit config. `com.unity.test-framework` is in `Packages/manifest.json` but no tests exist.

## Script layout (7 files, all in `Assets/Scripts/`)
- `Core/GameManager.cs` — lives, win/lose state, line completion counting
- `Arrows/ArrowLineController.cs` — line reset/complete, hint highlight, safety check
- `Arrows/ArrowheadController.cs` — mouse drag via **Unity Input System** (`Mouse.current`), path movement, collision → `GameManager.HandleCollision`
- `Arrows/ArrowPath.cs` — Catmull-Rom spline sampled into a `LineRenderer` (`[RequireComponent(typeof(LineRenderer))]`); needs ≥2 control points
- `Gameplay/HintManager.cs` — highlights a safely movable line
- `UI/GameUIController.cs` — win/lose panels, Retry button (TextMesh Pro text)

## Editor wiring gotchas (missing references fail silently or log errors)
- All cross-object links are `[SerializeField]` Inspector assignments: `GameManager.gameUI`/`livesText`, `ArrowLineController.gameManager`, `ArrowheadController.gameManager`/`lineController`/`oppositeArrowhead`, `HintManager.gameManager`. Verify these in the Inspector after touching prefabs/scene objects.
- `ArrowheadController` reads `Camera.main` — the scene needs a camera tagged MainCamera.
- Input uses the **new Input System** package (`com.unity.inputsystem` 1.18.0) via `Mouse.current`; `Assets/InputSystem_Actions.inputactions` exists but is not used by any code.
- UI text uses **TextMesh Pro** (`TMPro`).
- `ArrowPath.GeneratePath()` writes to `LineRenderer`; `ResetLine()` regenerates it. Path edits go through `controlPoints` Transforms on the `ArrowPath` GameObject.
